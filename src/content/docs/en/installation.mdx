How you acquire and install Remote Incident Manager depends on your mobile configuration, but in any case the process is quite straight forward.
<Windows>
### Installation
Remote Incident Manager is designed to work equally across iPhone and iPad. Simply [download Remote Incident Manager via the App Store](https://example.com) and you will be good to go.

### Permissions

Remote Incident Manager requires a minimal number of permissions to run optimally on iOS. You will be prompted for each permission when it is needed.

#### Microphone Access

RIM will request permission to access the microphone the first time you initiate a voice conversation. The microphone is not used for any other purpose.

#### Local Network Access

If you connect to a computer located on your local network, i.e., your home computer while you are within Wi-Fi range, RIM will ask you for permission to access devices over the local network. Granting this permission will give you the fastest possible connection experience.  
RIM will never access any devices on the local network beyond the local  computers you connect to.
</Windows>
<MacOS>
### Installation

The installation process for the Android version of RIM depends on what type of Android device you have.

#### Typical Installation

In most cases, you will install RIM through the Google Play Store.

#### Non-Google Play Installation

Android devices that lack Google Play capability will usually have an alternate method of installing RIM. In particular, many Android-based assistive technology products feature an app catalog where Remote Incident Manager may be located.  
In the event a direct avenue for installing RIM is unavailable, you can  manually download and install RIM on your Android device.

### Permissions

Remote Incident Manager requires a minimal number of permissions to run optimally on Android. You will be prompted for each permission when it is needed.

### Keyboard Input

IN order to send keyboard input to a remote computer, RIM leverages an accessibility service that captures the input of a physically connected keyboard. Enabling this service will ensure smooth operation of the keyboard, even when TalkBack is enabled.  
RIM will ask you to enable this permission if a physical keyboard is connected.

#### Microphone Access

RIM will request permission to access the microphone the first time you initiate a voice conversation. The microphone is not used for any other purpose.

#### Nearby Devices Access

If you connect to a computer located on your local network, i.e., your home computer while you are within Wi-Fi range, RIM will ask you for permission to access nearby devices over the local network. Granting this permission will give you the fastest possible connection experience.  
RIM will never access any devices on the local network beyond the local  computers you connect to.

</MacOS>
